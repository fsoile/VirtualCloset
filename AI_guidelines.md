# Using AI (Cursor) in Your Data Structures Project

## Overview
You are required to use an AI-assisted coding tool (Cursor) as part of your development process. 
The goal is **not** to have the AI complete the project for you, but to learn how to:

- Design a system before coding
- Ask precise technical questions
- Evaluate and verify generated code
- Iterate and improve solutions

---

# Required Workflow

You must follow this process. Skipping steps will result in a lower grade.

---

## Step 1: Design First (No AI Coding Yet)

Before writing any code, you must:

### Define:
- Project idea
- Classes (at least 2–3)
- Data members for each class
- Function members for each class
- Data structures used (stack/queue)

---

## Step 2: Guided Code Generation with AI

Once your design is complete, begin using Cursor.

### Important Rule:
> You may NOT ask the AI to “build the entire project.”

Instead, you must guide it step-by-step.

---

## How to Prompt Effectively

### Good Prompts (Specific and Controlled)

- “Generate a C++ header file for this class with these data members and functions: …”
- “Implement the `undo()` function using a stack. Explain each step.”
- “Write unit tests for this class.”
- “Explain what this line of code does.”

---

### Bad Prompts (Not Allowed)

- “Write the whole project for me”
- “Build a full GUI app”
- “Do everything”

---

## Required Development Process

For EACH class:

### 1. Generate Class Structure
- Ask AI to create `.h` file from your detailed class description
- Verify correctness

---

### 2. Implement Functions
- Ask for one function at a time
- Understand the logic before moving on

---

### 3. Ask for Explanation
- You must ask:
  - “Explain how this works”
  - “Why is this data structure used?”

---

### 4. Write Tests
- Ask AI:
  - “Generate test code for this class”
- Run tests and verify output

---

### 5. Modify Code
- Ask for improvements:
  - “Refactor this function”
  - “Add error handling”
  - “Optimize memory usage”

---

## Testing Requirement

You must:
- Test each class independently
- Show sample inputs and outputs
- Verify correctness manually

---

## Asking Questions (REQUIRED)

You must demonstrate curiosity and understanding.

Examples:
- “Why is a stack better than a queue here?”
- “What happens if the stack is empty?”
- “Can this cause a memory issue?”

---

## Prompt History Submission

You must submit your **AI interaction history**.

### ✔ Requirements:
- Show all prompts and responses
- Include:
  - Code generation prompts
  - Explanation questions
  - Debugging questions
  - Refinement requests

---
## Tips for Success

- Treat AI like a **junior programmer you supervise**
- Be specific and intentional
- Always ask “why”
- Verify everything

---

## 🎯 Final Thought

> The goal is not to see what AI can build.  
> The goal is to show how well **you can think, design, and guide AI**.
